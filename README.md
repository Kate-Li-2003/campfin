# Campaign Finance ML Classifier
Pull and clean campaign finance data from the [California Secretary of State](https://www.sos.ca.gov/campaign-lobbying/helpful-resources/raw-data-campaign-finance-and-lobbying-activity), and generate ML-based classifications of the industry (2-digit NAICS code) for each donor that can't be classified using OpenSecrets data. 

## Overview

This project monitors campaign finance donations made to candidates in California's 2025-2026 election cycle, with a focus on the Governor's race, Lieutenant Governor Race, and Insurance Commissioner's race. It does this by: 

- Fetching live election data from the [California Secretary of State](https://www.sos.ca.gov/campaign-lobbying/helpful-resources/raw-data-campaign-finance-and-lobbying-activity), filtering for large donations (above a certain $$ threshold) 
- Assigning industry classifications to donors using:
  -   **OpenSecrets Data**, a running database of individuals & their affiliations with a native industry classification system; 
  -   **[H1B Employer Datahub](https://www.uscis.gov/tools/reports-and-studies/h-1b-employer-data-hub)**, which assigns NAICs codes to H1B employers;
  -   **[California's Employment Development Department](https://labormarketinfo.edd.ca.gov/aspdotnet/databrowsing/empMain.aspx?menuChoice=emp)**, which assigns NAICS codes to California-based employers
  -  **A ML algorithm**, which predicts the industry of a donor given their Employer or Occupation 
- It generates:
  - An output file containing the classified industries for each large donor, including their employer, occupation, and donation size

### Prerequisites

- Python 3.13+
- Virtual environment installed, with packages in `requirements.txt`

### Setup

1. Clone the repository:
```bash
git clone <repository-url>
cd campaignfinancecategorization
```

2. Install dependencies:
```bash
python3 -m venv .venv
pip install -r requirements.txt
```

## Usage

### Data Pulling from Cal-Access

To pull **all donations** for a race, run: 

```bash
.venv/bin/python code/04_donations_data_pull/pull_calaccess.py --races [GOV/LTG/IC]
```

Pulled data will be stored at `data/01CalAccess_CampaignFinance_Data/governor_race_2026.csv`.

To pull all data for the governor's race _above_ a specific donation amount (e.g., 5K), run:
```bash
.venv/bin/python code/04_donations_data_pull/0401_filter_10k_donations.py \ --inputs “data/01CalAccess_CampaignFinance_Data/governor_race_2026-04-27.csv” \ --amount-min 5000
```

Filtered contributions data will be stored at `data/04_output_latest_data_pulls/0401_races_5kfilters/governor_race_2026_over_5k.csv`

### Classifications (Static) 

To generate matches using static/dynamic lookup sources **ONLY**, run:
```bash
python code/05_candidate_industry_affiliations/0504_classify_other_races.py --inputs
extra/powersearch_2526/power_search_candidates_2526.csv --out-dir output/05_output
```
This routes output to `output/05_output`, under `..._classified.csv`

### Classifications (SVM) 

To generate matches using **classifier** **predictions**, run:
```bash
python code/07_ml_unmatched_classifier/0702_predict_unmatched.py --inputs output/05_output/power_search_candidates_2526_classified.csv
```
This routes output to `data/07_output_ml_classification/`, under `...classified_with_ml.csv`
